¡Bienvenido a **Mokepon**! Un videojuego web de batallas por turnos inspirado en mecánicas clásicas de RPG y el famoso juego de "Piedra, Papel o Tijera", desarrollado con JavaScript, HTML5 Canvas y Express.

---

## 🚀 Características
- **Selección de Personajes:** Elige entre Hipodoge (Agua), Capipepo (Tierra) o Ratigueya (Fuego).
- **Mapa Interactivo con HTML5 Canvas:** Explora el mapa en 2D y colisiona con otros personajes para iniciar batallas.
- **Lógica Dinámica por Turnos:** Batallas en tiempo real con sistema de ataques y contraataques elementales.
- **Servidor Backend (Express):** Manejo de peticiones HTTP para sincronización de jugadores y mapa.
- **Diseño Responsivo:** Interfaz adaptada para pantallas de escritorio y dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5 & Canvas API:** Maquetación semántica y renderizado de gráficos 2D.
- **CSS3:** Flexbox, CSS Grid y diseño adaptativo.
- **JavaScript (ES6):** Programación Orientada a Objetos (POO), manejo de eventos del DOM y promesas.
- **Node.js & Express:** Servidor backend ligero para gestión de red.

---

## 📦 Instalación y Ejecución Local

1. **Clona este repositorio:**
   ```bash
   git clone git@github.com:stevenmoralesc/mokepon-game.git
   cd mokepon-game
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Inicia el servidor:**
   ```bash
   node index.js
   ```

4. **Abre el juego:**
   Ingresa a `http://localhost:8080` en tu navegador.
