# 🦖 Mokepon - Batalla de Mascotas

¡Bienvenido a **Mokepon**! Un videojuego web de batallas por turnos inspirado en mecánicas clásicas de RPG y el famoso juego de "Piedra, Papel o Tijera", desarrollado como parte de mi aprendizaje en Programación Básica.



[Image of web application responsive design preview]


## 🚀 Características
- **Selección de Personajes:** Elige entre Hipodoge (Agua), Capipepo (Tierra) o Ratigueya (Fuego).
- **Lógica Dinámica por Turnos:** El enemigo responde de forma inteligente usando su propio set de ataques.
- **Diseño Retro Arcade:** Interfaz optimizada con estética de pixeles y paleta de colores de videojuegos clásicos.
- **Totalmente Responsivo:** Adaptado para jugarse tanto en computadoras como en dispositivos móviles.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica del tablero de juego.
- **CSS3:** Maquetación con Flexbox, CSS Grid y variables de diseño adaptativo.
- **JavaScript (ES6):** Programación Orientada a Objetos (POO), manipulación del DOM y lógica de estado del juego.
